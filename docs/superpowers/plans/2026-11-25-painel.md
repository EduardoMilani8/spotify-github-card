# Painel único Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/api/painel`, um SVG 840×356 com cara de repositório do GitHub e 4 quadros (tocando agora, álbuns do mês, última review do Letterboxd, top 4 filmes).

**Architecture:** Funções puras (leitor do RSS, quebra de texto, renderizador) + orquestrador com injeção de dependências, como `gerar-card.ts` e `gerar-vitrine.ts`. O disco e o carrossel saem dos renderizadores atuais como peças parametrizadas por prefixo de id, usadas pelos cards atuais e pelo painel.

**Tech Stack:** TypeScript ~5.9 (ESM NodeNext, imports `.js`), Vitest, Node 22, Vercel Functions, `fast-xml-parser` 5.

**Spec:** `docs/superpowers/specs/2026-11-25-painel-design.md`

## Global Constraints

- Resposta **sempre 200** com SVG válido; `Content-Type: image/svg+xml; charset=utf-8`; `Cache-Control: no-cache, no-store, max-age=0`, sem `CDN-Cache-Control`.
- Painel só em português; sem `?lang`.
- Rotas atuais (`/api/now-playing`, `/api/showcase`, `/api/open`) não mudam de comportamento; os testes atuais continuam verdes.
- Todo texto externo passa por `escaparXml`.
- Nenhum `id` repetido no SVG do painel.
- Só CSS dentro do SVG; `prefers-reduced-motion` para tudo.
- Letterboxd: `https://letterboxd.com/${LETTERBOXD_USER}/rss/`; pôster da review em `0-150-0-225`, do top 4 em `0-70-0-105`.
- Memo dos dados lentos: 1h; 60s se a última tentativa teve erro.

## Review Focus

1. Review com HTML estranho (entidades `&amp;`, `<br>`, vários `<p>`, aviso de spoiler, emoji) → trecho limpo, sem tags, sem cortar no meio de um par surrogate.
2. Item do RSS com `memberRating` ausente ou fora de 0.5–5 → sem estrelas, sem crash.
3. RSS com um item só (fast-xml-parser devolve objeto, não array) → ainda acha a review.
4. Ids/keyframes do carrossel e do disco convivendo no mesmo SVG → nenhum `id` duplicado, cards antigos byte a byte iguais.
5. Memo: falha do Letterboxd não pode ficar guardada por 1h; Spotify (tocando agora) nunca é memorizado.

### Task 1: Leitor do RSS do Letterboxd

**Files:** Create `src/painel/tipos.ts`, `src/painel/letterboxd.ts`, `tests/painel/letterboxd.test.ts`, `tests/fixtures/letterboxd.xml` (sintético, mesma estrutura do RSS real). Modify `package.json` (`fast-xml-parser` → `dependencies`), `.env.example` (`LETTERBOXD_USER=`).

**Interfaces — Produces:**
- `interface Review { filme: string; nota: number | null; trecho: string; posterUrl: string | null; assistidoEm: string /* YYYY-MM-DD */ }`
- `escolherReview(xml: string): Review | null`
- `buscarRss(usuario: string, fetchFn: FetchFn): Promise<string>` (lança em HTTP não-ok; timeout 2500ms)
- `estrelas(nota: number | null): string` → `'★★★★½'`
- `dataCurta(iso: string): string` → `'9 ago'`

Testes: fixture com lista + item sem texto + review com spoiler e entidades + review válida; escolhe a 1ª válida; pôster trocado para 150×225; trecho sem tags e sem aviso de spoiler; item único (objeto); XML quebrado/vazio → `null`; `estrelas` 4.5/1/0.5/null/7; `dataCurta`.

### Task 2: Quebra de texto e top 4

**Files:** Create `src/painel/quebrar-texto.ts`, `src/painel/top4.ts`, `tests/painel/quebrar-texto.test.ts`.

**Produces:**
- `quebrarLinhas(texto: string, larguraMax: number, fontSize: number, maxLinhas: number): string[]` — usa `larguraEstimada`; última linha termina em `…` se sobrou texto; palavra maior que a linha é cortada por caractere.
- `interface Filme { titulo: string; ano: number; direcao: string; posterUrl: string }`, `TOP4: Filme[]` (spec 2.4).

### Task 3: Peças reaproveitáveis do disco e do carrossel

**Files:** Modify `src/render-svg.ts`, `src/vitrine/render-vitrine.ts`. Test: `tests/render-svg.test.ts`, `tests/vitrine/render-vitrine.test.ts`.

**Produces:**
- `render-svg.ts`: `discoElementos(centro: string): string` (anéis + centro + aro + furo), `bracoElementos(): string`.
- `render-vitrine.ts`: `corpoVitrine(albuns: Album[], capas: (string|null)[], opcoes: OpcoesVitrine): { tipo: 'carrossel'|'estatico'|'vazio'; css; defs; elementos; indicador: string }` com `OpcoesVitrine { prefixo: string; fundo: string; fonteTitulo: [number, number]; mensagemVazia: string }`. Todos os ids e `url(#…)`/`href="#…"` recebem o prefixo. `renderizarVitrine` passa a usar `corpoVitrine` com prefixo `''`.

Testes: SVG dos cards atuais idêntico a antes (snapshot gravado antes da refatoração); `corpoVitrine` com prefixo `a-` não tem nenhum `id="` sem o prefixo.

### Task 4: `renderizarPainel`

Testes: XML válido (fast-xml-parser `XMLValidator`), classe do estado na raiz, textos dos 4 estados, 3/1–2/0 álbuns, review vazia, estrelas, trecho em 2 linhas, top 4 com 4 nomes, ids únicos, `prefers-reduced-motion`, escape de `<&`.
